# Project Hero Images

Add your project hero images to this folder with these exact names:

## Required Images:

1. **husky-match-hero.png** - Hero image for Husky Match project
2. **smartassist-hero.png** - Hero image for SmartAssist Coursera project
3. **apple-fitness-hero.png** - Hero image for Apple Fitness Studio project

## Image Guidelines:

- **Format**: PNG or JPG
- **Recommended dimensions**: 800x600px or similar aspect ratio
- **File size**: Keep under 500KB for optimal loading
- **Content**: Use the first slide/cover of your presentation or a representative graphic

## Tips for Best Results:

1. Use high-quality images with transparent backgrounds (PNG) if possible
2. Ensure logos and text are clearly visible
3. Images will be displayed at 320px wide on desktop
4. Consider using your presentation cover slides

## Example:
If your presentation has a cover slide with the project logo and key visual, export that slide as an image and place it here.
