# Software Logos

Add your software logo images to this folder.

## File Naming Convention

Use lowercase names with the `.svg` or `.png` extension:
- `figma.svg`
- `notion.svg`
- `tableau.svg`
- `powerbi.svg`
- `jira.svg`
- etc.

## Supported Formats

- **SVG** (recommended) - Scalable vector graphics work best
- **PNG** - Use transparent backgrounds for best results

## Logo Guidelines

- **Size**: Logos should be square or close to square (1:1 aspect ratio)
- **Background**: Use transparent backgrounds
- **Colors**: Logos will be displayed with opacity, so ensure good contrast
- **Dimensions**: Recommended 200x200px minimum for PNG, scalable for SVG

## Current Software List

The software names are defined in `lib/data/software.ts`. Add logos here matching the names in that file.
